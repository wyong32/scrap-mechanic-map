# Scrap Mechanic 1.0 官方地块图集设计

## 目标

消除默认 DB、玩家上传存档及固定区域中的分类色块和空白。地图继续优先使用
`the1killer/sm_overview` 已有的高分辨率俯视图；旧资源缺失时，自动使用当前
Scrap Mechanic 1.0 安装目录内与 `.tile` 同目录的官方 UUID 预览 PNG。

## 数据流水线

1. 读取已生成的 `tile-catalog.json`，用每条记录的 `relativePath` 精确定位同目录
   `<uuid>.png`，避免同名 UUID 出现在不同目录时选错资源。
2. 验证官方预览为 220×150，并按固定菱形边界
   `(109,37) (215,93) (110,149) (4,93)` 做双线性逆映射，生成 256×256 方形纹理。
3. 将每个 UUID 的完整地块纹理按规范顺序装入 4096×4096 WebP 图集页，生成带尺寸、
   跨格大小、来源和 SHA-256 的清单。
4. 浏览器启动时一次预载清单和图集页。旧版资源解析失败后，按 UUID 解析官方图集。

## 渲染与多格地块

同一地块实例由 `xOffset/yOffset` 还原原点，并用目录中的 `width/height` 确认范围。
完整且一致的多格实例只绘制一次完整纹理，再应用存档中的四向旋转；无法完整成组时，
按偏移裁切对应子格，以保证边界存档仍有真实纹理而不是色块。

## 验收

- 默认 `bilige.db` 的 12,288 格全部有图片，缺失 UUID 为 0。
- 覆盖统计分别显示旧版图片、1.0 官方图片和缺失色块，且默认 DB 缺失色块为 0。
- 固定区域与上传存档共用相同解析器。
- 图集、清单、运行时解析和裁切均有自动化测试；执行完整测试和生产构建。
