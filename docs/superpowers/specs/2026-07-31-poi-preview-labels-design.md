# POI 场景预览与地点名称设计

## 目标

修正地表地图中大型 POI 官方预览遮挡底图、随地块旋转而倒立的问题，并为存档中的可识别 POI 提供可选的通用中文名称。

## 展示规则

1. 官方 POI 预览拆成地面层和场景图标层。
2. 地面层使用官方 TileEditor 预览校正得到的正俯视地形，按存档中的占地、坐标和旋转铺满原区域。
3. 场景图标使用去除编辑器背景后的官方预览，绘制在 POI 占地区域中心。
4. 场景图标不跟随地块旋转，始终保持统一正向。
5. 场景图标的屏幕尺寸限制在 24–64px；大型 POI 不再把场景图放大至整个占地区域。
6. 现有“POI”图层继续控制 POI 场景图标。
7. 新增“地点名称”图层复选框，默认不勾选；它只控制文字标签，不改变地面层或场景图标。
8. 勾选“地点名称”后，所有缩放级别均显示名称。

## 名称规则

名称从存档地块的 `poiType` 和官方 tile 路径确定。同类地点使用相同通用名称，不添加序号、楼层或人为专名。

首批映射：

- 所有 Warehouse 变体：`仓库`
- RuinCity：`废墟城区`
- Hideout：`藏身处`
- PackingStation_Fruit：`水果包装站`
- PackingStation_Vegetable：`蔬菜包装站`
- SchematicStation：`蓝图工作站`
- Kiosk：`售货亭`
- BunkInvestigationQuest：`调查掩体`
- ChemicalPlant_Road：`化学池设施`
- FarmingPatch：`农田`
- 无法安全映射的 POI：不显示名称，不使用 UUID 或内部 ID 代替

重复地点保留相同名称，例如所有 2、3、4 层仓库均只显示“仓库”。

## 数据与渲染

### 官方图集

`official-tile-atlas` 为 `isometric-thumbnail` 条目生成两种独立资源：

- `terrain`：正俯视校正后的完整地面；
- `icon`：去背景的官方场景预览。

图集清单记录两个源矩形。旧的普通地形条目继续使用单一 `terrain` 源矩形。

### 存档 POI 实例

解析地形时，以 UUID、旋转、偏移和占地范围合并多格 POI。每个实例只产生一个场景图标和一个可选名称锚点，避免每格重复。

### Canvas 与标签

- Canvas 先按地块旋转绘制正俯视地面，再在实例中心以零旋转绘制缩小后的图标。
- 地点名称作为独立 Leaflet 图层绘制，锚点取实例占地区域中心。
- 名称图层状态进入 URL 的 `layers` 参数；默认状态不包含名称图层。

## 兼容与失败处理

- 缺少图标资源时，仅绘制真实地面，不显示空白或占位图标。
- 无名称映射时仍绘制场景图标，但不创建文字标签。
- 旧版原仓资源的地形和已有固定地点标记保持不变。
- 用户上传存档与默认 DB 使用同一套实例识别和名称规则。

## 测试与验收

自动测试覆盖：

1. 仓库不同楼层和重复实例都映射为“仓库”，不含序号。
2. 未知 POI 不生成臆造名称。
3. 多格 POI 只生成一个实例锚点。
4. 地面按存档旋转，图标旋转角恒为零。
5. 图标屏幕尺寸始终处于 24–64px。
6. “地点名称”默认关闭，URL 勾选状态可恢复。
7. 图标资源缺失时仍正常绘制地面。

浏览器验收覆盖用户截图附近的仓库、废墟城区、藏身处和包装站：

- 地面连续且保留真实布局；
- 场景图不倒立；
- 场景图不再覆盖整个大型区域；
- 名称默认不显示；
- 勾选后显示通用名称且无序号。
